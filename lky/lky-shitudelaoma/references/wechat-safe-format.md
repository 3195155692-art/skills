# 微信导入安全写法

公众号编辑器对 Markdown 兼容很差，下面这些写法会直接被渲染成空白或乱码。
交付前用 `scripts/check_article.py` 扫一遍，不要靠肉眼。

| 禁止 | 为什么 | 改成 |
|---|---|---|
| `- **名称**：说明` | 列表项内嵌加粗加中文冒号，导入后整行空白 | `· **名称**：说明` 独立段落（中间点 U+00B7 + 空格） |
| `* xxx` / `+ xxx` | 同属列表语法，前缀会丢 | 用 `· ` 或普通段落 |
| `1. xxx` 起头的行 | 有序列表前缀同样可能被吞，且在部分渲染器里会变成编号列表 | 小标题用 `### 2.1 标题`，正文并列用 `（1）` |
| 小目录用列表 | 锚点列表导入后变成空白行 | 普通段落 `一、章节名`，逐行排列 |
| `[文字](https://...)` | 外链会被平台清掉 | 纯文本写 `期刊. 年份.`，不加链接 |
| Markdown 表格（竖线语法） | 表格语法不解析，会显示成竖线堆 | matplotlib 画成 PNG 再插图 |
| emoji | 部分版本渲染为方框或直接丢失 | 去掉，改用文字标题 |
| `≤` `≥` `→` `α` `β` 等非 ASCII 符号 | 易乱码，也会让 matplotlib 出方框 | `<=` `>=` `->` `alpha` `beta` |
| 灰色或彩色图注 | 与统一黑色的标准冲突 | 图注用黑色，docx 里 14px（10.5pt）、居中，图注后空一行 |
| 单文件大于 15MB | 公众号导入上限 | 图片压到 1200px 宽，PNG 用 optimize |
| `![图](C:\path\x.png)` 这类本机绝对路径 | 换台机器就打不开 | 相对路径 `./km_fig1.png`，与文章同目录 |

例外：图片引用 `![图注](路径)` 与 md 内部锚点 `[章节](#锚点)` 不受链接禁令限制。

图片里中文显示成方框是另一个独立问题（matplotlib 字体），处理办法见 [figures.md](figures.md)。
