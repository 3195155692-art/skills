# 跟着老马学生信 · 规范

成品：`跟着老马学生信（N）：主题.docx`，配图 `{前缀}_fig{N}_{描述}.png` 与 docx 同目录。
每期讲一个生信方法、概念、工具或数据库。

输出方式与文献精读共用一套：先写内容 JSON，再用 `scripts/build_docx.py` 渲染成 docx，
不要手搓 docx 脚本。版式参数见 [docx-format.md](docx-format.md)；本系列的差别只在章节骨架、
配图来源与声明文字。

## 结构

```
主标题：跟着老马学生信（N）：主题
副标题：一句提炼
小目录（普通段落，形如 一、xxx）
开篇：用一个真实痛点或常见错误切入，不要从定义开始
正文章节：按「是什么 -> 为什么 -> 怎么做」展开
常见问题（Q&A，>= 10 条）
写在最后
参考文献
```

受主题影响，正文章节可以合并或扩展，但「是什么 / 为什么 / 怎么做」这条主线不要丢。
方法类主题尽量加一张方法对比表（把 2–3 个相关方法在原理、适用场景、优缺点三个维度对比），
对比表用 matplotlib 画成 PNG，且对比结论必须加「本模拟设定下」一类限定并给文献佐证，
不写「X 优于 Y」。

## 配图

- 每篇 >= 6 张，300dpi，matplotlib / seaborn 生成，不用网络来源图片。
- 每张图写成 `image` block，图注用 `图N 一句话说明`，脱离正文也能读懂。
- 第一张图图注下方加一行：`（声明：本文图片均为模拟生成，不代表真实数据）`。
  JSON 顶层写 `"series": "学生信"` 时，`build_docx.py` 会自动拿这句当默认声明文字。
- 模拟数据的 fold change 控制在 0.1–0.6，信息基因 10–15 个，避免 AUC 出现 1.000 这种假完美结果。
- 命名前缀按期数主题取简写（`rf_` 随机森林、`svm_`、`lasso_`、`lr_`、`cs_`、`vko_`、`tv_` 等），
  没有约定就用 `fig{N}_{描述}.png`。

## Q&A

>= 10 条，覆盖原理理解、数据准备、实操问题、结果解读四个维度，
优先写网上真实高频的坑（社区帖、官方 FAQ、审稿意见）。整节写成一个 `qa` block：

```json
{"type": "qa", "items": [["问题标题", "解答内容"], ["问题标题", "解答内容"]]}
```

渲染后每问一段 `[问题] 问题标题`，紧接一段 `[回答] 解答内容`。不要用 `❓` `✅` 之类的符号。

## 代码

正文只讲核心调用和关键参数解读，完整可运行代码放附录，并在附录开头注明运行环境。
优先用用户提供的真实项目代码；没有真实代码时先跟用户确认，不要编模板代码充数。
代码写成 `code` block，`lang` 标语言：

```json
{"type": "code", "lang": "r", "text": "完整可运行代码，按原样换行"}
```

渲染成等宽字体（Consolas 10.5pt）的段落；自检脚本会跳过这些段落，不在代码里扫破折号与列表语法。

## 参考文献

逐条写进 JSON 的 `references` 数组，纯文本，不带超链接与 DOI：

```
[N] Author et al. Title. Journal. Year.（JCR Qx，YYYY IF x.x，中科院x区）
```

优先引用原始方法论文。引用本系列往期内容时写成「本系列第 N 期」，不要加链接。

## 内容 JSON 骨架

```json
{
  "series": "学生信",
  "title": "跟着老马学生信（N）：主题",
  "subtitle": "一句提炼",
  "fig_dir": "/绝对路径/第N期 主题",
  "output": "/绝对路径/第N期 主题/跟着老马学生信（N）：主题.docx",
  "intro": ["开篇钩子段落，放在小目录之后、正文之前"],
  "toc": ["一、xxx", "二、xxx"],
  "sections": [
    {"heading": "一、xxx", "level": 1, "blocks": [
      {"type": "para", "text": "正文段落"},
      {"type": "point", "items": [["名称", "说明"]]},
      {"type": "image", "file": "rf_fig1_xxx.png", "caption": "图1 说明。", "disclaimer": true}
    ]},
    {"heading": "常见问题", "level": 1, "blocks": [{"type": "qa", "items": [["问", "答"]]}]},
    {"heading": "附录：完整代码", "level": 1, "blocks": [{"type": "code", "lang": "r", "text": "..."}]}
  ],
  "references": ["[1] Author et al. Title. Journal. Year."],
  "footnote": ["本文图片均为模拟生成，仅供学习交流。"]
}
```

学生信不写 `snapshot`，论文快照是文献精读专用的字段。
