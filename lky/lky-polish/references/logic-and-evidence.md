# 第二轮：段落逻辑与证据强度

去 AI 味处理的是语气和节奏，这一轮处理文章怎样组织主张、证据和限制。两轮都做，顺序不要颠倒。

## 硬约束

1. 不新增、删除、修改引用、作者年份、样本量、OR、CI、P 值、HR、SMD、GWAS ID、PMID、药物名、基因名。
2. 不改变证据强度。原文是「可能」不要改成「会」，原文是「候选」不要改成「核心」。
3. 不把观察性关联写成因果。
4. 表格内数值默认不改，只改表题、表注和正文引导句。
5. 拿不准时保留原句，并列入「需作者确认」。

## 工作流

### 1. 判断段落功能

先判断当前段落承担哪一种任务：

- 背景引入
- 机制解释
- 证据汇总
- 矛盾或边界说明
- 过渡整合
- 结论或研究议程

一个段落承担多种任务时，判断是否需要分层或拆分，避免多个层面挤在同一段里。

### 2. 标出主张、证据与限制

逐一确认：

- 主张是什么。
- 证据来自哪里。
- 证据强度如何。
- 限制是什么。
- 与前文、后文是什么关系。

引用应紧贴它支持的主张。句子里出现结论，却找不到就近证据时，先检查是否只是语序问题，不能自行补引用。

### 3. 查找逻辑缺口

重点检查：

- 开头是否缺主体。
- 句间是否缺因果、对比、递进或让步。
- 证据和结论的强度是否匹配。
- 是否把「相关」写成「因果」。
- 同一段是否塞了多个层面。
- 引用是否紧贴对应主张。
- 反面证据、条件限制和适用边界是否被删掉。

### 4. 明确结构

常见组织方式是：主题句、证据展开、机制解释、边界、收束。按内容需要调整，不必机械套满五步。

遇到复杂论证时，可以用这些方法分层：

- 层面化：中枢层面、外周器官介质层面、时间关系层面。
- 两端对照：就 xx 端而言，就 yy 端而言。
- 前后呼应：与前文不同、相比之下、因此。

只增加原稿逻辑真正需要的组织方式。

### 5. 补足逻辑连接

从下面选择最准确的一个，不缺逻辑关系时不要添加。

**引入主题**

在……层面；就……而言；与……相比；与前述通道不同；现有证据中最一致的发现是。

**递进**

此外；进一步看；与此同时；除……外；值得注意的是。

**对比与转折**

然而；不过；相比之下；与之相对；尽管……但……；二者并非同一机制的简单翻转。

**因果与推论**

因此；因而；由此；从而；这提示；这些结果支持。

**收束**

总体而言；综合来看；就现阶段而言；因此，……仍应视为待验证的候选机制；其因果关系的确立，仍需……。

连接词不能成串。因果句式只能连接原稿已有的推论，不得凭空补出新因果。

### 6. 最后校验

逐项核对：

- 引用是否未变。
- 作者年份、样本量、效应量、置信区间、检验值等数据是否未变。
- 术语是否一致。
- 证据强度是否未被升级。
- 表格数值、表题、表注和图注是否未被误改。
- 是否产生新的因果断言。
- 是否删除或弱化了原有局限。

任何一项无法确认，保留原句并写入「需作者确认」。
